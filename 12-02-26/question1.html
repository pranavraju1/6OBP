Bootstrap is a free and open‑source CSS framework directed at responsive, mobile‑first front‑end web development.

Bootstrap helps you build responsive layouts quickly and consistently across browsers, with ready‑made components like buttons, cards, navbars, and modals.

Bootstrap is mainly a CSS framework, but it includes JavaScript components (like modal, accordion, dropdowns) that you can use with plain HTML.
